What gets in the way

Collecting fees

How Hourhand handles it

Weekly repeat bookings

A student keeps the same slot every week for up to 12 weeks, with reminders before each class.

Group classes with a seat limit

Set the number of seats for a batch. When it fills, a waitlist takes the next names.

Booking in five languages

Parents book in Hindi, Tamil, Telugu, Kannada or English, and can add a second guest such as the student.

Holidays in one go

Packages by UPI
